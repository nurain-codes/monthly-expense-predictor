# 💰 Monthly Expense Predictor

A beginner-friendly Machine Learning mini project that predicts monthly expenses using a trained Random Forest Regression model.

## Files needed

Keep these files in the same folder:

- `app.py`
- `expense_prediction_model.pkl`
- `requirements.txt`

## Setup

Open the VS Code terminal in the project folder.

Make sure your virtual environment is activated, then run:

```bash
pip install -r requirements.txt
```

## Run the web app

```bash
streamlit run app.py
```

A browser window should open with the Expense Predictor interface.

If it does not open automatically, the terminal will show a local address such as:

`http://localhost:8501`

Open that address in your browser.

## Important

The `expense_prediction_model.pkl` file is your trained Random Forest model. Keep it in the same folder as `app.py`.
